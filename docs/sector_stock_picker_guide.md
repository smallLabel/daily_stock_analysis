# 板块选股功能使用说明

## 功能概述

板块选股功能可以帮助你找到大盘中最具潜力的板块，并从这些板块中筛选出优质个股进行推荐。

### 主要特点

1. **排除创业板和科创板**：自动过滤掉300开头（创业板）和688开头（科创板）的股票
2. **多维度板块分析**：
   -涨跌幅排名
   - 资金流入情况
   - 板块热度
   - 板块内个股表现

3. **严格的个股筛选**：
   - 趋势分析（MA5>MA10>MA20多头排列）
   - MACD指标分析
   - RSI强度分析
   - 量能形态分析
   - 支撑压力位分析

4. **智能评分系统**：
   - 板块潜力评分（0-100分）
   - 个股信号评分（0-100分）
   - 只推荐评分>=60的个股

## 使用方法

### 1. 命令行方式

```bash
# 运行测试脚本
python test_sector_picker.py
```

该脚本会：
- 分析前10个最具潜力的板块
- 从每个板块中推荐前3只个股
- 生成详细的分析报告
- 将报告保存到 `reports/` 目录

### 2. Python代码方式

```python
from src.sector_stock_picker import SectorStockPicker
from data_provider.base import DataFetcherManager

# 创建选股器
data_manager = DataFetcherManager()
picker = SectorStockPicker(data_manager=data_manager)

# 执行完整分析
result = picker.run_full_analysis(
    sector_top_n=10,  # 分析前10个板块
    stock_top_n=3      # 每个板块推荐3只个股
)

# 生成格式化报告
report = picker.format_report(result)
print(report)
```

### 3. 单独分析板块或个股

```python
# 只分析板块
sectors = picker.analyze_sectors(top_n=10)
for sector in sectors:
    print(f"{sector.name}: 评分 {sector.potential_score}")

# 从某个板块推荐个股
sector_info = sectors[0]  # 选择第一个板块
stocks = picker.recommend_stocks_from_sector(sector_info, top_n=5)
for stock in stocks:
    print(f"{stock.code} {stock.name}: {stock.buy_signal}")
```

## 分析结果说明

### 板块评分维度

1. **涨跌幅**（权重30%）
   - 今日涨幅>5%: 30分
   - 今日涨幅>3%: 25分
   - 今日涨幅>0%: 15分

2. **资金流入**（权重25%）
   - 流入>10亿: 25分
   - 流入>5亿: 20分
   - 流入>0: 10分

3. **板块内个股表现**（权重20%）
   - 上涨占比>80%: 20分
   - 上涨占比>60%: 15分
   - 上涨占比>50%: 10分

4. **板块热度**（权重25%）
   - 基于新闻数量和时效性计算

### 个股买入信号

- **强烈买入**：多头排列 + 零轴上金叉 + 缩量回调
- **买入**：多头排列 + MACD金叉或上穿零轴
- **持有**：趋势良好但暂无明确买点
- **观望**：趋势不明或处于调整期

## 注意事项

1. **数据依赖**：需要有效的数据源（Akshare、Tushare等）
2. **网络要求**：需要稳定的网络连接获取实时数据
3. **运行时间**：完整分析可能需要几分钟时间
4. **免责声明**：本功能仅供参考，不构成投资建议

## 常见问题

### Q: 为什么没有获取到板块数据？
A: 可能是网络问题或数据源API限制。建议：
- 检查网络连接
- 等待一段时间后重试
- 配置多个数据源作为备选

### Q: 如何调整筛选条件？
A: 修改 `sector_stock_picker.py` 中的评分逻辑：
- 调整各维度权重
- 修改评分阈值
- 自定义筛选规则

### Q: 如何增加推荐数量？
A: 在调用 `run_full_analysis` 时修改参数：
```python
result = picker.run_full_analysis(
    sector_top_n=20,  # 增加到20个板块
    stock_top_n=5     # 每个板块推荐5只
)
```
