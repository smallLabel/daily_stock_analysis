## 实现内容

### 1. 数据源架构

#### 当前数据源优先级：
```
1. Akshare（东方财富）- 优先 ⭐
   ├── 完全免费
   ├── 无需注册
   └── 数据全面
   
2. Tushare - 备用
   ├── 需要 Token
   ├── 有调用限制
   └── 作为故障转移
```

### 2. 核心修改

#### 文件 1：`data_provider/fetchers/akshare_fetcher.py`
新增 3 个基本面数据获取方法：

1. **get_financial_indicator(stock_code)**
   - 获取财务分析指标
   - 包含 ROE、ROA、净利率等关键指标

2. **get_balance_sheet(stock_code)**
   - 获取资产负债表数据
   - 包含流动资产、负债等信息

3. **get_income_statement(stock_code)**
   - 获取利润表数据
   - 包含营收、净利润等信息

#### 文件 2：`src/analyzers/fundamental_analyzer.py`
修改核心分析逻辑：

1. **初始化数据管理器**
   ```python
   self._data_manager = DataFetcherManager()
   ```

2. **实现数据源优先级策略**
   - 优先尝试 Akshare
   - 失败后自动降级到 Tushare
   - 清晰的日志记录

3. **新增辅助方法**
   - `_get_profitability_from_akshare()` - Akshare 数据获取
   - `_get_profitability_from_tushare()` - Tushare 数据获取

### 3. 智能特性

#### 故障转移（Failover）
```python
# 伪代码示例
result = try_akshare()
if result.failed:
    result = try_tushare()
return result
```

#### 列名智能匹配
```python
# 支持多种可能的列名
roe_cols = ['净资产收益率', 'ROE', 'roe', '加权净资产收益率']
for col in roe_cols:
    if col in data:
        value = data[col]
        break
```

#### 缓存机制
- TTL: 24小时
- 减少 API 调用
- 提高响应速度

- 建议同一分析任务使用同一数据源

- 24小时缓存已足够
