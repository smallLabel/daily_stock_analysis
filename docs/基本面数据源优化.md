# 基本面数据源优化 - 优先使用 efinance/akshare

## 概述

已成功将基本面数据获取逻辑修改为**优先从 efinance/akshare 获取基本面数据**，Tushare 作为备用数据源。

## 修改内容

### 1. 在 `AkshareFetcher` 中添加基本面数据获取方法

文件：`data_provider/fetchers/akshare_fetcher.py`

新增以下方法：

#### `get_financial_indicator(stock_code: str)` - 获取财务指标
- 数据源：`ak.stock_financial_analysis_indicator()`
- 包含指标：
  - 净资产收益率 (ROE)
  - 总资产收益率 (ROA)
  - 销售净利率
  - 每股收益 (EPS)
  - 每股净资产
  - 每股经营现金流
  - 市盈率 (PE)
  - 市净率 (PB)
  等财务指标

#### `get_balance_sheet(stock_code: str)` - 获取资产负债表
- 数据源：`ak.stock_balance_sheet_by_report_em()`
- 包含完整的资产负债表数据

#### `get_income_statement(stock_code: str)` - 获取利润表
- 数据源：`ak.stock_profit_sheet_by_report_em()`
- 包含完整的利润表数据

### 2. 修改 `FundamentalAnalyzer` 使用 Akshare 优先

文件：`src/analyzers/fundamental_analyzer.py`

#### 主要变化：

1. **初始化数据管理器**
   ```python
   from data_provider.core.manager import DataFetcherManager
   self._data_manager = DataFetcherManager()
   ```

2. **数据源优先级**
   - 第一优先：Akshare（免费开源，东方财富数据）
   - 第二优先：Tushare（需要 Token，数据更专业）

3. **新增辅助方法**
   - `_get_profitability_from_akshare(code)` - 从 Akshare 获取盈利能力指标
   - `_get_profitability_from_tushare(code)` - 从 Tushare 获取盈利能力指标（原有逻辑）

4. **智能降级机制**
   - 优先尝试 Akshare
   - 失败后自动降级到 Tushare
   - 记录日志便于调试

## 优势

### 1. 免费开源
- Akshare 完全免费，无需任何 Token 或注册
- Efinance 同样免费且无需认证

### 2. 数据全面
- 东方财富是中国领先的金融数据提供商
- Akshare 提供的财务指标数据非常详尽

### 3. 高可用性
- 多数据源故障转移
- Akshare 失败时自动切换到 Tushare
- 提高系统整体稳定性

### 4. 易于维护
- 统一通过 `DataFetcherManager` 管理
- 清晰的日志记录
- 便于调试和排查问题

## 使用示例

### 直接使用 AkshareFetcher

```python
from data_provider.fetchers.akshare_fetcher import AkshareFetcher

fetcher = AkshareFetcher()

# 获取财务指标
df = fetcher.get_financial_indicator('600519')
print(df.iloc[0])  # 显示最新一期数据

# 获取资产负债表
balance = fetcher.get_balance_sheet('600519')

# 获取利润表
income = fetcher.get_income_statement('600519')
```

### 使用 FundamentalAnalyzer（推荐）

```python
from src.config import get_config
from src.analyzers.fundamental_analyzer import FundamentalAnalyzer

config = get_config()
analyzer = FundamentalAnalyzer(config)

# 完整的财务健康度分析
health = analyzer.analyze_financial_health('600519')

if health.get('available'):
    print(f"盈利能力: {health.get('profitability')}")
    print(f"成长性: {health.get('growth')}")
    print(f"估值: {health.get('valuation')}")
    print(f"安全性: {health.get('safety')}")
```

## 数据源对比

| 特性 | Efinance/Akshare | Tushare |
|------|------------------|---------|
| 费用 | 完全免费 | 需要 Token |
| 认证 | 无需认证 | 需要注册 |
| 数据来源 | 东方财富 | 专业金融数据 |
| 覆盖范围 | A股、港股、美股 | 主要是 A股 |
| 更新频率 | 实时 | 延迟 15-30 分钟（免费版）|
| 稳定性 | 较高 | 高 |

## 注意事项

1. **优先级配置**
   - 当前配置为 Akshare 优先
   - 如果 Akshare 获取失败，会自动尝试 Tushare
   - 如果两者都失败，会返回错误信息

2. **数据一致性**
   - Akshare 和 Tushare 的数据可能存在细微差异
   - 建议优先使用同一数据源进行长期分析

3. **API 限制**
   - Akshare 需要遵守反爬虫策略（已内置延迟和重试机制）
   - Tushare 有 API 调用频率限制（尤其是免费用户）
